# 🔥 Real-Time Object Detection App (TensorFlow Hub + Streamlit)

A **real-time object detection web application** built using **Streamlit**, **TensorFlow Hub**, and **OpenCV**.  
It detects multiple objects from **webcam, images, and videos** using a pre-trained SSD MobileNet model trained on OpenImages dataset.

---

## 🚀 Features

- 📷 Real-time webcam object detection  
- 🖼️ Image upload detection  
- 🎥 Video upload detection  
- 🧠 Pre-trained TensorFlow Hub model  
- 🎯 Multiple object detection (Person, Car, Table, etc.)  
- 🟢 Bounding boxes with labels and confidence scores  
- 🎨 Random color coding for each object class  
- ⚡ Fast inference using SSD MobileNet V2  

---

## 🧠 Model Information

- Model: **SSD MobileNet V2**
- Dataset: **OpenImages V4**
- Source: TensorFlow Hub
